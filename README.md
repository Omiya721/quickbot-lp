# 【自主制作】AIチャットボット導入LP（QuickBot）

AIチャットボットの導入を促す、BtoB向けのサービスLP（ランディングページ）です。
実務での「運用のしやすさ」を想定し、WordPressの最新エディタ（Gutenberg）へのカスタマイズを行いました。

## 🌐 制作概要
- **制作期間**: 9日間
- **仕様**: レスポンシブ対応（PC / スマホ）、WordPressテーマ化
- **目的**: 専門知識がないクライアントでも、デザインを保ったまま、直感的にコンテンツの追加や文言修正ができるストレスフリーな運用環境の構築

## 🛠️ 使用技術・ツール
- **言語**: HTML5, CSS3, JavaScript, PHP, WordPress
- **主要プラグイン**: 
  - **Advanced Custom Fields PRO**: ACF Blocks機能を用いたカスタムブロック化
  - **Contact Form 7**: お問い合わせフォームの実装・カスタマイズ
  - **EWWW Image Optimizer**: 次世代画像フォーマット（WebP等）への対応、および画像軽量化によるサイト高速化
  - **UpdraftPlus**: 万が一のトラブルに備えた、実務想定の自動バックアップ・復元環境の構築
- **デザイン**: Figma (コミュニティ配布のテンプレートを使用)

  - テンプレート名: [BtoB ランディングページ ワイヤーフレーム]

## ✨ 実装・設計のこだわり（アピールポイント）
- **ACF Blocksによるブロックエディタ化**
  クライアント側での自由なページ運用や文言修正を想定し、各セクションをカスタムブロック化して実装しています。
  専門的なHTML/CSSの知識がなくても、管理画面から直感的にコンテンツの追加・並び替え・文言修正が可能で、マニュアル不要の運用性を実現しました。
- **実務を想定したサイト運用設計**
  フォームの実装だけでなく、画像の自動最適化（高速化）や、定期的なバックアップ環境の構築まで一通りプラグインを導入・検証しており、納品後すぐに実運用に耐えうる実務レベルのサイト設計を意識しました。

## 💡 生成AIツールの活用について
本プロジェクトでは、開発効率の向上とコードの品質担保のため、GoogleGemini等の生成AIを「開発パートナー」として活用しています。
単なるコードの丸投げではなく、全体のコンポーネント設計やACFのデータ構造を自身で定義した上で、適切なコードの生成、デバッグ、リファクタリングを指示し、実務を意識したスピード感のある開発を行いました。
